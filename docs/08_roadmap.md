# Proponowane etapy po badaniu źródeł

**10.09.2026 — rekomendacja, nie rozpoczęta implementacja.**

| Etap | Wartość dla użytkownika | Warunki wejścia / zakończenia |
|---|---|---|
| MVP — pilot dokumentacyjny | Raport jednego projektu: znane punkty, dowody, kierunkowy pipeline, opublikowane moce, inwestycje i braki | Wybrać obszar na podstawie dowodów, wyjaśnić prawa źródeł, przetestować pierwsze parsery, zweryfikować relacje; bez arbitralnego score |
| V1 — rozszerzenie pokrycia | Kilku operatorów/obszarów, historia zmian, deduplikacja, konflikty, kontrola źródeł, podstawowa mapa dowodów | Mierzalna kompletność i poprawność na próbie referencyjnej; stabilna automatyzacja zgodna z warunkami |
| V2 — scenariusze i warunkowa analityka | Kandydaci przyłączenia, import/eksport BESS, ograniczenia PCC, warianty przyszłej sieci i trasy GIS | Zweryfikowane wejścia i zakres stosowalności; scoring tylko po osobnym opracowaniu i walidacji |
| LONG-TERM — model techniczny | Analizy elektryczne i lepsza kalibracja wyników dla uprawnionych obszarów | Dane operatora/inwestora: topologia, parametry, profile, zdarzenia N-1; referencyjne wyniki studiów |

Najbliższy proponowany krok: etap 2, czyli zamknięcie zakresu pierwszego raportu, wybór źródeł z podstawą wykorzystania, model danych i wybór regionu pilotażowego. Nie wybierać GPZ wyłącznie na podstawie liczby obiektów OSM. PSE jako pierwszy kanał strukturalny i obszar Energi/ENEA jako kandydat lokalny wymagają sprawdzenia konkretnego zestawu dowodów.

Rozbudowa UI następuje po wiarygodnym raporcie danych. Ogólnopolskie pokrycie nie jest warunkiem sukcesu pilota. Brak lokalnych danych elektrycznych może pozostać trwałą granicą produktu opartego wyłącznie na danych publicznych.
