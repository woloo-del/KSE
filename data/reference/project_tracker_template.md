# Źródło szablonu raportu

Szablon Project Tracker został wybrany przez użytkownika w trakcie pracy 10.09.2026. Zachowana kopia `project_tracker_template.xlsx` pochodzi z pakietu `openai-templates` 0.1.1, umiejętność `artifact-template-project-tracker`, zasób `assets/reference.xlsx`.

Jest to niezmieniony szablon zawierający fikcyjne demonstracyjne zadania, osoby i daty. Nie są to dane projektu KSE. Generator importuje szablon i zastępuje wszystkie demonstracyjne wejścia danymi z rejestru TODO przed eksportem. Hash kopii jest zapisywany w każdym manifeście raportu. Szablon nie jest źródłem informacji o infrastrukturze energetycznej.
